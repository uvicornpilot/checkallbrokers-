Створи головну сторінку для сайту "Broker Control" — аналітичного проєкту, що займається перевіркою брокерів і наданням юридичних консультацій жертвам шахрайських компаній. Сторінка має бути зверстана у HTML + CSS (без фреймворків).

🔹 Вимоги до дизайну:
- Сучасний чистий стиль, без перевантаження.
- Основний акцент: довіра, юридична допомога, аналітика.
- Зелений як колір CTA (кнопок).
- Добре адаптується під мобільні екрани (можна використовувати flex або grid).

🔹 Структура сторінки:

1. **Хедер**:
   - Зліва логотип (можна плейсхолдер).
   - Назва: `Broker Control`
   - Підзаголовок: `Анализ и оценка брокерских компаний`
   - Справа або під логотипом — банер:  
     ```
     Обманул брокер?  
     Бесплатная юридическая консультация  
     [Кнопка: Оставить заявку]
     ```

2. **Про проект** (блок About):
   - Коротко і стилізовано розкажи про проєкт: хто ми, що робимо, кому допомагаємо.
   - Додай текст:
     ```
     Broker Control — это независимый информационно-аналитический проект...
     Мы проверяем лицензии, условия торговли, собираем отзывы...
     Команду составляют юристы, трейдеры и аналитики.
     ```

3. **Наші Цілі / Послуги**:
   - Три картки в ряд (або в стовпчик на мобільному):  
     - `Защита клиентов`  
     - `Консультации`  
     - `Информирование`  
   - Кожна з іконкою або мінімальним стилем.

4. **Банер \"Подобрать брокера\"**:
   - Текст + кнопка \"Заполнить заявку\".

5. **Блог (список статей)**:
   - Мінімум 1-2 пост-картки:
     - Заголовок, короткий опис, кнопка `Читать далее`

6. **Форма зворотного зв'язку**:
   - Окрема секція з якорем `#consult-form`
   - Поля:
     - Ім’я
     - Телефон
     - Проблема (textarea)
     - Кнопка `Отправить`

7. **Попап форма**:
   - Через 3 секунди після завантаження сторінки — з'являється модальне вікно:
     ```
     Потерял деньги? Не знаете что делать?
     Получите бесплатную консультацию!
     [Форма]
     ```

8. **Футер** — звичайний, назва сайту, копірайт.

🧩 Додатково:
- Забезпеч валідну HTML-структуру.
- Створи окремий CSS-файл (чи блок style) для стилів: кнопки, секції, layout, кольори.
- Уникай Bootstrap чи Tailwind — тільки чистий CSS.
